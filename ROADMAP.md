# Roadmap

> **This is upstream [openGym](https://github.com/DuarteSantos8/openGym)'s public roadmap, kept in
> this fork for provenance only.** OlyGym is a personal, local-only fork: it has no releases of its
> own, it does not follow this plan, and it has removed a large part of what the plan describes
> (self-hosting, accounts and sync, push, the AI Coach, the MCP bridge, the marketing site and
> more). Nothing below should be read as a promise about this fork.

Upstream's plan, in their words, is a release every two weeks with one small theme per release, and
milestones tracked as GitHub milestones:

- **Milestones:** https://github.com/DuarteSantos8/openGym/milestones
- **Source:** https://github.com/DuarteSantos8/openGym

For what this fork actually does today, see [README.md](README.md).
